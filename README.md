# MF-Line-Best

Cloudflare 边缘入口的延迟测量结果，每日刷新。

逐个实测 HTTP TTFB 与丢包率，按国家取最快的若干条。
国家与机房由机房码经公开的机房码对照表判定，不采用源文件的标注。

## 文件

| 路径 | 内容 |
|---|---|
| `all/all.txt` | 全量，按国家分组 |
| `top/top{10,20,50,100}.txt` | 最快 N 条，按 TTFB 排序 |
| `region/*.txt` | 按 Cloudflare 业务分区拆分，每轮全量产出 |
| `config/mf.ini` | 配套的 subconverter 重命名与分组规则 |
| `config/mf-rename-only.ini` | 同上，但不含分流规则 |

每行格式：

```
104.18.33.46:2096#SG-MF-01-CF
188.164.248.0:2083#SG-MF-02-3rd
```

`CF` 表示该地址属于 Cloudflare 官方公布的 IP 段，`3rd` 表示第三方中转地址。

## 说明

结果仅为特定观测点在特定时刻的测量值，不代表其他网络环境下的表现。
本仓库不提供任何服务，只发布测量数据。
